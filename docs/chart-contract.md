# 图表实现约定

来源：[用户补充的 ECharts skill](../echart/SKILL.md)。该 skill 已读取，后续图表实现优先复用其选型与格式规范，并遵守项目的金融数据证据要求。

## 渲染方式

- 聊天产品由 React 图表组件调用 `echarts.init()` 和 `setOption()`，不依赖宿主聊天软件自动识别代码块。
- Markdown 导出如需内嵌图表，使用严格 JSON 的 `echarts` 代码块；不把图表 option 作为独立 JSON 文件交付。
- 模型只选择受控图表类型、数据集 ID 和列名。后端验证数据与引用，前端构造 option；不执行模型生成的 JavaScript、formatter 函数或任意 HTML。
- 图表实例在组件卸载时 dispose，容器大小变化时 resize；后续实现时验证历史对话重载与图表状态恢复。

## 图表选型与样式

- 时间序列用折线；分类比较用柱状图。超过六类或长标签优先横向排序柱状图。
- 默认不生成雷达图、热力图、甘特图。市场状态的七个维度用文字/表格，不强行画雷达图。
- 不同单位优先拆图；双 Y 轴只在明确需要时采用，并明确单位和对应系列。
- 单个坐标网格，`containLabel: true`。图例在顶部，标题和图例预留各自空间；缩放条另留底部空间，避免与标签重叠。
- 使用 skill 的温暖简约色板作为候选默认；系列颜色设置在 series 层，逐项突出时使用数据项静态配置，不使用函数。
- 涨跌颜色与普通系列颜色分开配置，保留正负号和文字。颜色不能独自承担“上涨/下跌/缺失”的表达。
- 轴标签和轴线采用清晰深灰色。数据多时使用 tooltip 和缩放，稀疏点可直接显示数值。
- 显示数值最多两位小数；单位写在轴名/表头。底层计算与证据保留原始精度，不把带单位字符串作为数值。
- 交易日日线默认类别轴，避免休市空白被误读为缺失；盘中图只有在时间戳/时区明确时使用时间轴。

## 金融证据补充约束

每张图必须与文字共享同一数据集与证据版本，显示来源、实际数据时点、单位、区间和必要的样本口径。来源信息放在图表外的可访问 HTML 说明区，不挤进绘图区。

图表标题中的判断必须来自已验证指标；没有充分证据时使用中性标题，不为满足“洞察型标题”而编造结论。

归一化比较采用共同起点，注明基期和价格/全收益口径。缺失值保留 null 和断点，不填零、不擅自插值；全无有效数据时呈现不可用原因，不渲染正常空图。

提供“查看数据表”和文字摘要，键盘可访问图表相关操作。图表数据导出须遵循数据授权范围。首版不使用生成图片替代可操作的数据图表。
