## 2. AI 参与的环节

1. **需求与资源核查**（Codex）：阅读原始需求、工具包与数据源文档，形成规划与核查记录（[01](01_产品与技术实施规划.md)、[02](02_工具包与数据源核查.md)）。
2. **接入验证**（Codex）：编写连接探针并分别真实验证 DeepSeek、扶摇、iFinD（[03](03_接入准备与验证记录.md)、[04](04_iFinD数据能力与质量验证.md)）。
3. **产品实现**：第一版由 Codex 完成，包括研究编排、数据适配、确定性指标、证据追溯接口和 Web 界面；Claude Code 接手后接入估值与事件，并按验收结果修正。
4. **验证**：离线测试由 Codex 建立，Claude Code 补充；真实单次研究和 19 个用例的真实验收脚本由 Claude Code 编写（[05 测试说明](05_测试说明.md)）。
5. **部署准备**（Claude Code）：发布前密钥扫描、git 仓库、本机 + Cloudflare 隧道公开访问及其验证。
6. **产品运行时**：DeepSeek 完成意图识别、取数规划与观点选择。

## 3. 验证中发现并修正的问题

以下由编码助手在检查真实结果或自检时发现并修正，属于 AI 自检修正，不是人工修正。第 1–3 条在接入阶段，由 Codex 完成；第 4–14 条由 Claude Code 完成。

| # | 发现方式 | 问题 | 修正 |
|---|---|---|---|
| 1 | 接入阶段测试失败（见 03） | MCP 协议测试替换 `httpx.AsyncClient` 的方式破坏了 SDK 导入时的类型注解 | 改为客户端子类，保留类型身份 |
| 2 | 接入阶段文档自检（见 03） | 注释中"全部禁止重定向"的描述与 SDK 实际行为不符 | 按安装版本核对后修正描述 |
| 3 | 真实 iFinD 响应检查（见 04） | 固定日期参数可能错误批准同一张表中其他日期的行 | 增加逐行日期核对与回归测试 |
| 4 | 代码阅读（2026-10-07） | 估值与事件的取数函数已经写好，但没有注册为 Agent 工具，七维中这两项永远显示"待核实" | 接入为工具；失败时如实显示"已调用，未通过核验（原因）" |
| 5 | 文件核对 | 新建技能文件里写的改编来源路径不存在（误写为 `basics/`、`masters/`） | 用 `find` 核对后改为实际路径 `hackers/info-analysis.md`、`hackers/event-price-in.md` |
| 6 | 真实单次研究（运行 `b9c432c4…`） | 估值、事件证据已经取得，但模型没有选入归纳，界面"如何理解这些证据"里看不到这两维 | 有核验证据但未被选中的估值、风险变量、重要事件观点，由代码追加到归纳末尾（不涉及模型生成） |
| 7 | 真实验收（`work/acceptance-20261007-150953.json`） | "末日涨跌停分布有哪些风险信号？"被模型识别为概念解释，返回了"市场宽度是什么"的定义，没有取数 | 修改识别提示；加规则兜底：非定义式问法且含风险类词时改为风险研究；新增回归测试 |
| 8 | 同上验收报告 | 风格、行业问题本来没调用宽度工具，却显示"市场宽度：缺失或覆盖不足"；截至日为 2026-08-31 时估值显示"当前 PE/PB" | 维度状态区分"本轮未调用"与"已调用未通过"；估值措辞改为"截至日" |
| 9 | 同上验收报告 | 大盘概览从不调用涨跌停数据，"情绪"维度总是缺失 | 概览也尝试取涨跌停；只有明确问到风险时才强制把风险观点放进归纳 |
| 10 | 文件核对 | `.env.example` 缺少 `IFIND_NEWS_URL`、`MARKET_PUBLIC`、`MARKET_ACCESS_CODE`；后两项实际只从进程环境变量读取 | 补齐并在注释和 README 中说明读取位置 |
| 11 | README 与代码对照 | 旧 README 写"Web 主链路尚未实现"，与已有代码不符；测试数量仍写 61 项 | 按实际运行证据重写 README 与验收清单 |
| 12 | 真实验收（`acceptance-20261007-152329`）的校验记录 | 模型把主要矛盾 ID 放进摘要 ID，两次重试都犯同样的错，结果只展示了事实 | 剔除非观点 ID 后再渲染（只删不增），重试提示列出可用 ID；最终验收中该用例恢复正常归纳 |
| 13 | 个股研究纳入范围后的合规复查 | "可以买入吗""要不要卖""值不值得入手"等问法不在原有拦截规则内 | 扩展拦截规则并加单元测试与真实验收用例，确认"相对沪深300表现如何"这类研究问题不被误拦 |
| 14 | 发布前检查待提交文件 | `.claude/settings.local.json`（本机权限配置）不在 `.gitignore` 中，会被提交 | 加入 `.gitignore`；提交前用 `.env.local` 中每个密钥值逐一扫描待提交文件，未发现泄露 |
