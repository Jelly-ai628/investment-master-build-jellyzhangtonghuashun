## 4. 数据平台与模型核查结果

### 扶摇：已读公开文档，未做账号鉴权调用

- API 使用 `https://fuyao.aicubes.cn`，请求头 `X-api-key`。同时检查 HTTP 状态与业务 `code`，并记录 `request_id`。
- 普通业务成功 `code=0`；鉴权、权限、未就绪、限流、上游失败有不同业务码。文档说明 HTTP 429 或 `code=4001` 都需按限流处理。
- 有股票快照、历史行情、指数历史日线、当前成分、近一年交易日、涨跌停和热榜等接口文档。
- 指数历史 K 线单次一个指数，日线窗口不超过十年；无指数复权参数。
- 日历固定 `[今日-1年, 今日]`，成分接口明确是当前成分，不满足严格历史成分回溯需求。
- 已读估值接口是最新 A 股个股快照：PE TTM/MRQ、PB MRQ、PS TTM、PCF TTM。明确不提供历史估值，不可直接实现指数历史估值分位。
- 主力资金和资讯事件库页面明确标注“暂未开放外部接入”。即便总目录/MCP 总表有相关条目，实施仍按具体能力页限制处理，不尝试绕过。

### iFinD：已读公开页面，账号能力待验证

- 公开数据范围包含证券基础指标、宏观行业指标和公告资讯搜索，涉及指数估值和板块分析。
- 接入指南要求登录后在个人中心获取 MCP 密钥、选择数据服务并生成配置。具体 endpoint、认证头、transport、tools/list 与字段 schema 以用户实际配置和服务返回为准，不猜测。
- 页面存在按套餐/用户权限的调用权益，不能假设无限额度。市场宽度、融资、利率、政策原文和历史估值是本项目优先验证项。
- “两套数据平台互补”是待验证的实施方向，不能当作七个维度已全部覆盖的结论。

### DeepSeek：已读官方文档，未调用模型

- 官方文档说明兼容 API 格式、支持 streaming 与 tool calls；本次首页列出 deepseek-flash、deepseek-v4-pro。
- 工具是应用服务端实际执行，模型只返回调用请求。DeepSeek Key 不提供扶摇或 iFinD 的数据权限。
- 接入选择模型 ID、思考模式、工具回填及结构化输出后需要真实冒烟测试。Beta strict 工具 schema 并不能代替应用层完整校验。
