### 通用配置说明

本地环境已执行 `uv sync`。其他环境复现：

```bash
uv sync --locked
uv run pytest -q
uv run python scripts/check_connections.py
```

默认命令只检查配置存在性，不发送网络请求。检查结果为 configured_unverified 时，也不代表凭据正确。

用户在项目根目录 `.env.local` 本地填写即可，无需将密钥粘贴到聊天：

| 配置 | 填写方法 |
|---|---|
| DEEPSEEK_API_KEY | 用户已有 DeepSeek API Key |
| DEEPSEEK_MODEL | 先使用文档中的 deepseek-flash；运行前会核对账号模型目录，未命中则停止 |
| FUYAO_API_KEY | 登录扶摇后，在 API Key 管理页获取用户授权的 Key |
| IFIND_MCP_URL | iFinD 个人中心 → MCP → 选所需数据服务 → 生成配置；填写其中的准确 endpoint |
| IFIND_MCP_TRANSPORT | 生成配置为 HTTP/Streamable HTTP 时填 streamable_http；SSE 时填 sse，不自动轮试 |
| IFIND_MCP_AUTH_HEADER | 如果生成配置使用 headers，填实际认证头名 |
| IFIND_MCP_AUTH_VALUE | 填认证头的完整值；仅在配置明确要求时包含 Bearer 前缀 |

若 iFinD 凭据已包含在 endpoint query/path 中，完整地址也视为密钥，保留在 `.env.local`，不要贴到 README 或聊天。若生成配置包含多个服务 endpoint，先接一个与本项目相关的数据服务；其他服务后续分别核验。当前探针默认只允许 HTTPS 的 51ifind.com 及其子域，若平台生成其他域名，需核实后扩充，不盲目转发凭据。

接入说明入口：

- [扶摇快速开始](https://fuyao.aicubes.cn/docs/quickstart/) / [API Key 管理](https://fuyao.aicubes.cn/admin/)。
- [iFinD 接入准备](https://mcp.51ifind.com/#/docs/guide-prepare)。
- [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/)。

填好后，真实探针命令为：

```bash
uv run python scripts/check_connections.py --live --provider deepseek
uv run python scripts/check_connections.py --live --provider fuyao
uv run python scripts/check_connections.py --live --provider ifind
```

DeepSeek 探针会产生最多两次小规模模型请求，使用明确标为 synthetic 的本地连接测试值，不发送飞书原文、个人投资数据或受限行情。扶摇探针仅取日历、代码解析和一个指数约20日日线。iFinD 当前只发现工具，不自动调用未知数据工具。三者均无自动重试，以免未明失败时重复消耗额度。

## 38 项离线测试结果

命令：`uv run pytest -q --tb=short`。实际结果：**38 passed in 0.42s**。测试全部使用本地构造响应和 MockTransport，没有真实金融数据调用，没有真实 DeepSeek 推理调用。

覆盖：

- 扶摇 HTTP 200 + 业务错误、未认证、权限不足、未就绪、限流、上游失败。
- 空数据、非法 schema、重复日期、未来时间、日期与毫秒戳矛盾。
- 缺失、字符串、非有限数、零/负价格不被静默当作正常收盘价。
- 日历 → 指数解析 → 日线的完整调用链；缺交易日不能通过。
- DeepSeek 工具白名单、工具参数、tool_call_id 回填、流式完成标记；流提前中断不能通过。
- 默认配置检查不联网；配置值不进入报告；网络错误信息不泄露含敏感参数的 URL。
- iFinD endpoint 范围与认证头完整性检查。
- **实际官方 MCP SDK + 本地 HTTP MockTransport** 的初始化、initialized 通知和两页工具发现流程。只验证协议集成，不等于 iFinD 账号已接通。旧 SSE 传输当前仅完成导入与代码接线，未做真实服务验证。

接入准备阶段由编码助手完成 skill 阅读、适配器和测试编写、本地命令执行与文档更新，该阶段未调用 DeepSeek。用户配置后追加进行了上文所记的 DeepSeek 真实验证，测试调用模型为 deepseek-flash。

1. 官方 MCP SDK 的函数签名和重定向规则以实际安装版本检查，修正文档/注释中“全部禁止重定向”的过宽描述；SDK 将重定向限制在同源规则内。

两项均为 AI 自检与修正，没有将其记为用户人工修正。用户本轮提供了 ECharts skill，作为后续图表规范来源。
