# 个股研究 v2

## 适用问题

"贵州茅台最近表现如何""600519 相对大盘怎么样"。

## 取数计划

1. 代码：只使用服务端在扶摇 A 股代码表中精确匹配到的代码，禁止凭记忆补全；匹配不到就如实说明，不用指数或其他股票代替。
2. get_stock_history：该股前复权日 K，计算区间首末变化、最大回撤、均线位置和区间收盘高低点位置。
3. get_index_history(000300.SH)：同区间的大盘对照，只作参照，不能代替该股。
4. get_stock_valuation：最新 PE/PB 快照。

## 怎么读证据

- 先看该股自身：方向、回撤、区间位置；再看相对沪深300：是强于还是弱于，差多少个百分点。
- 区分"跟随大盘"和"独立走势"：同一区间大盘也在下跌时，个股下跌未必来自公司自身。
- 完整的个股诊断还需要盈利能力、财务健康、成长性、估值历史分位和资金动向。本产品只接入了价格和估值快照，其余维度显示为未核实，不用常识补齐。

## 选择与排序

- 摘要必须以该股的 index_*（个股行情）或 relative_*（相对大盘）开头。
- 主要矛盾选 stock_vs_market：相对强弱不能归因于基本面、资金或行业。

## 边界

"能买吗""该卖吗""值不值得入手"在取数前已被拦截。研究结果中不出现买卖时机、目标价、止损位、支撑压力位或时机评分；区间高低点只描述已发生的位置。
