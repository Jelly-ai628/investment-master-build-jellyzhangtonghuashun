# 重要事件与原文核对 v2

## 适用问题

"最近有什么政策或事件""央行做了什么操作"，以及"市场为什么涨/跌"中涉及事件的部分。

## 取数计划

- get_event_context：检索研究区间末段（最近约 7 个交易日）中国人民银行公开市场操作、逆回购相关的报道，并打开报道源网页核对标题与日期。
- 同时取沪深300区间行情，只用来说明事件发生时市场处于什么状态。

## 怎么读证据

1. 先确认事实：发布时间、来源、原文标题。媒体报道不等于央行原始公告；拟实施的安排不等于已经实施。
2. 再看覆盖：只检索了流动性相关报道，不能宣称覆盖了全部政策和重要事件。
3. 归因要分开：事件和价格变化同时出现，不构成因果。要判断一个事件是否"已被定价"，需要事件前后的价格反应、预期与实际的差异，并排除同期的其他事件；这些证据没有时，"已被定价""利好兑现"只能作为待验证假设。
4. 不做利好利空计数：报道条数和措辞倾向，不能代表事件影响的大小。
5. 检索不到或原文核对失败时，明确记为事件证据缺失，不用常识补写事件。

## 选择与排序

- 事件问题：摘要必须包含 events_*；主要矛盾选 evidence_gaps。
- 用户问"为什么涨/跌"时，先给已发生的行情，再给事件报道，并保留"不能证明因果"的限制。

## 边界

不根据事件推断后续走势，不给出事件驱动的操作建议。
